# Couchsurf.ru

Сервис для поиска гостеприимных хостов и совместных приключений.

## Быстрый старт

```bash
npm install
npm run dev
```

### Скрипты

- `npm run dev` — запуск режима разработки.
- `npm run build` — сборка production-версии.
- `npm run start` — запуск собранного приложения.
